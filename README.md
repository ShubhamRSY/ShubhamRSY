```mermaid
flowchart LR
    U([User intent]) --> P{{Planner LLM}}
    P -->|decompose| T1[Tools: SQL / APIs]
    P -->|retrieve| T2[RAG / Vector store]
    P -->|connect| T3[MCP servers]
    T1 & T2 & T3 --> R[Reasoning loop]
    R -->|self-check| E{Evaluator}
```
